# Checkpoint 3.2.1: tracking evaluation foundation

Date: 19 October 2026

## Scope

This checkpoint creates the test bench that future tracker implementations will
use. It intentionally contains no production tracker.

```text
Saved per-frame observations -> ordered replay -> tracker (later) -> reviewed
target assignments -> common identity metrics
```

## Decisions

- `v3.2` is one project folder. Later checkpoints use names such as `3.2.2`
  and `3.2.3` inside the same folder.
- v3.2 carries a source snapshot of v3.1 and does not import v3.1 at runtime.
- Large models, data, and videos remain in the parent v3 project.
- An observation fixture represents one sensor and preserves every frame,
  including frames with no detections.
- Frame sequence numbers must increase, timestamps must not move backwards, and
  frame IDs must be unique.
- Observation IDs must be unique across the entire fixture.
- Tracker comparison will use the same saved detector observations for every
  candidate.
- Initial metrics are deliberately transparent single-target POC measures:
  track coverage, missed visible frames, identity switches, fragmentations,
  unique assigned IDs, and unmatched track instances.
- The metrics are not advertised as MOTChallenge/HOTA metrics; their exact
  definitions live in the code and tests.

## Acceptance checks

- the saved synthetic fixture loads and replays `detection -> gap -> detection`;
- empty frames survive serialization and replay;
- JSON save/load is lossless for the defined records;
- mixed sensors, duplicate frames, and unordered sequences are rejected;
- metric assignments carry an explicit increasing sequence number;
- metric calculations are verified on known identity/gap examples;
- all inherited v3.1 tests and frozen v3 tests remain green.

## Result

**Pass.** All 44 v3.2 tests pass, including saved-fixture, replay, ordering,
identity, and metric-definition checks. All 31 frozen v3.1 tests and all 10
parent v3 regression tests also remain green. Python compilation passes.

No production tracker was installed or implemented during this checkpoint.
