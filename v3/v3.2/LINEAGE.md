# v3.2 lineage

The initial v3.2 source and tests were copied from the completed v3.1 modular
foundation on 19 October 2026.

Inherited capabilities:

- core frame, detection, observation, and local-track records;
- backend-neutral detector and tracker interfaces;
- Ultralytics detector adapter;
- deterministic observation construction and serialization;
- v3-to-v3.1 detector compatibility comparison utilities.

The v3.1 directory remains unchanged and is not a runtime dependency. Large
artifacts are shared from the parent v3 project rather than copied.
